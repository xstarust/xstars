| 华盖 | 子辰申→辰，丑巳酉→丑，寅午戌→戌，卯未亥→未 | match D::Shen/Zi/Chen → P::Chen 等 | ✅ |

| 寡宿 | 寅卯辰→丑，巳午未→辰，申酉戌→未，亥子丑→戌 | match 同上 | ✅ |
| 破碎 | 子午卯酉→巳，寅申巳亥→酉，辰戌丑未→丑 | match | ✅ |
